# 北京阳光北亚家政微信小程序 MVP

这是一个原生微信小程序家政预约示例，适合用微信开发者工具直接导入预览。

## 已完成功能

- 身份选择：区分客户端和阿姨端
- 首页：品牌展示、服务分类、服务保障、推荐阿姨
- 服务：客户看阿姨，阿姨看客户需求和工作机会
- 门店：城市搜索、区域筛选、可住宿筛选、门店列表和电话/导航入口
- 找阿姨：客户可按育儿嫂、月嫂、住家保姆、小时工筛选
- 阿姨详情：档案、价格、技能、保障、个人介绍
- 公司/门店信息：展示服务范围、服务区域、联系地址和服务点
- 今日推荐：客户看今日推荐阿姨，阿姨看今日推荐工作
- 预约面试：填写联系人、手机号、面试时间、地址和备注
- 发布需求：填写服务类型、上户时间、预算和家庭情况
- 阿姨工作台：完善资料、上传证件健康证、查看客户需求、申请接单
- 证件资料：身份证、健康证、技能证书选择与保存
- 需求大厅：展示客户需求，阿姨可申请接单
- 我的接单：查看阿姨申请记录
- 关于我们：展示公司介绍、服务流程、服务保障和客服入口
- 我的：查看当前会话里提交的需求和预约记录

## 运行方式

1. 打开微信开发者工具。
2. 选择“小程序”。
3. 点击“导入项目”。
4. 项目目录选择：`C:\Users\24225\Documents\New project 2`
5. AppID 使用测试号或你自己的小程序 AppID。
6. 后端服务选择“不使用云服务”。

## 后续可接入

- 微信手机号授权登录
- 云开发数据库保存阿姨资料和预约单
- 顾问后台管理预约
- 后台管理公司服务内容：服务范围、服务优势、门店信息、服务说明均要能在后台维护，前端点击后进入对应详情
- 城市切换和地图定位
- 真实支付、合同、保险和评价流程
