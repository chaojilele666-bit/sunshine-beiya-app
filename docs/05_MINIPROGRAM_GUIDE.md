# 小程序指南

## 身份

小程序当前有两个身份：

- 客户端：`customer`
- 阿姨端：`ayi`

当前仍是本地身份选择，正式微信登录未接入。

## 客户端

已实现：

- 首页身份栏。
- 公司展示轮播，来自后台 `banners`。
- 快捷入口：找阿姨、发布需求、客服咨询、公司介绍。
- 服务中心，来自后台 `serviceModules`。
- 阿姨列表和服务筛选。
- 阿姨详情。
- 门店列表和门店详情。
- 电话和导航。
- 发布客户需求。
- 需求详情、推荐阿姨、确认推荐、拒绝推荐。
- 我的页面查看本地可访问的需求记录。

待人工验证：

- 服务中心视觉效果。
- 后台上传服务图标后小程序同步显示。
- 需求推荐确认/拒绝的完整 UI 流程。

## 阿姨端

已实现：

- 阿姨首页工作机会。
- 阿姨资料。
- 证件上传。
- 我的接单。
- 查看开放需求。
- 申请接单。
- 我的页面。

当前限制：

- 正式微信登录未接入。
- 阿姨端权限仍需后续和真实登录绑定。

## 本地兜底

如果 `/api/miniprogram` 访问失败，小程序可能使用 `frontend/data/` 中的演示数据。兜底数据只用于本地展示，不代表后台提交成功。
