# 认证与权限

## 对外身份名称

后台只对外展示两种身份：

- 运营端：内部角色代码 `operator`
- 管理端：内部角色代码 `boss`

后台界面不得使用“老板端”“负责人端”“管理员端”等称呼。小程序身份仍为：

- 客户端：`customer`
- 阿姨端：`ayi`

## 账号模型

后台和小程序测试账号统一存储在 `user_accounts`：

- `username`
- `phone`
- `password_hash`
- `role`
- `related_profile_type`
- `related_profile_id`
- `status`
- `wechat_openid`
- `wechat_unionid`
- `failed_login_count`
- `locked_until`
- `last_login_at`

后台账号资料存储在 `backstage_accounts`，运营端可访问模块由 `permissions` 字段配置。登录后端会根据 `user_accounts.related_profile_type = 'backstage_accounts'` 和 `related_profile_id` 读取对应后台资料。

后台登录 session 存储在 `auth_sessions`。前端只拿到随机 token，数据库只保存 token hash、过期时间和撤销状态。

## 管理端

管理端是最高后台权限，可以：

- 查看全部经营数据；
- 创建、停用运营端账号；
- 给运营端分配模块权限；
- 查看和导出操作记录；
- 新增、修改、审核、上下架阿姨；
- 处理全部客户需求并推荐阿姨；
- 处理预约、申请、订单和人工派单；
- 管理门店、服务中心、首页轮播；
- 修改公司基础信息。

操作记录只能查看和导出。系统不提供修改、删除或清空审计日志的接口。

## 运营端

运营端负责日常业务执行，只能访问被管理端授权的业务模块：

- 阿姨管理
- 客户需求
- 预约面试
- 接单申请
- 订单跟进
- 人工派单
- 门店信息
- 服务中心
- 首页轮播

运营端禁止访问：

- 管理看板
- 账号权限
- 操作记录
- 操作记录导出
- 公司基础信息
- 最高权限设置

运营端不能创建或删除后台账号，不能修改自己的角色，不能给自己增加权限，不能把自己升级为管理端，不能查看或导出操作记录，也不能访问未授权模块。

## 前后端双重限制

前端：

- 管理端显示全部后台菜单；
- 运营端只显示授权模块；
- 运营端不显示管理看板、账号权限、操作记录、公司基础信息；
- 手动访问受限 hash 路由时返回后台首页，不渲染受限模块数据。

后端：

- `accessControl.js` 集中定义 `bossOnly` 和 `operatorAssignable` 资源；
- `/api/auth/me` 返回当前账号实际 `allowedResources`；
- 通用后台 CRUD、管理看板、公司基础信息、操作记录、需求推荐接口都进行后端权限判断；
- 未登录返回 401；
- 无权限返回 403；
- `customer` 和 `ayi` 禁止访问后台通用 CRUD，只能使用 `/api/miniprogram/...` 专用接口。

## 账号权限保护

账号权限页面仅管理端可访问。

后端对后台账号保存做白名单校验：

- 角色只能是“运营端”或“管理端”；
- 运营端可授权模块只能来自既定业务模块；
- 前端伪造任意角色或任意权限值会被拒绝；
- 运营端不能调用账号权限 API。

为兼容历史数据，没有后台资料的旧运营端账号会按原日常业务权限处理；一旦账号关联了 `backstage_accounts`，则以该账号的 `permissions` 为准。

## 操作记录

只有管理端可以：

- 查看操作记录；
- 检索操作记录；
- 查看修改前后 JSON；
- 导出操作记录 CSV。

`operator`、`customer`、`ayi` 访问操作记录接口返回 403，未登录返回 401。

导出操作本身也会写入 `audit_logs`：

- `entity_type = auditLogs`
- `action = export`

页面和导出会递归隐藏密码、token、session、openid、私钥、`customer_access_token_hash` 等敏感字段。

## V3.1 需求访问令牌

客户提交需求后：

- 小程序拿到原始 `accessToken`；
- 数据库只保存 SHA-256 hash；
- 需求详情、推荐列表、确认和拒绝通过 `X-Demand-Access-Token` 请求头传递 token；
- URL query 不接收 token；
- 日志中不打印完整 token。

## 当前限制

- 正式微信登录尚未接入；
- `wechat_openid` 和 `wechat_unionid` 仍为预留字段；
- 生产部署前还需要重新评估 HTTPS、token 存储、CSRF、限流、审计保留周期和备份策略。
