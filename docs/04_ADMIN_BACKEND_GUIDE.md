# 后台管理指南

## 登录身份

后台对外只显示两个身份：

- 运营端：内部角色 `operator`
- 管理端：内部角色 `boss`

客户端和阿姨端属于小程序身份，不作为后台登录身份展示。

## 页面路由

后台使用原生 HTML、CSS、JavaScript 和 hash 路由：

- `#/home`
- `#/dashboard`
- `#/accounts`
- `#/ayis`
- `#/demands`
- `#/appointments`
- `#/applications`
- `#/orders`
- `#/dispatches`
- `#/stores`
- `#/services`
- `#/banners`

后台首页显示功能入口卡片。功能模块页面应只显示当前模块内容。

## 管理模块

- 管理看板：统计和最近操作记录，管理端可见。
- 账号权限：账号和角色管理，管理端可见。
- 阿姨管理：阿姨资料、审核、证件、门店、推荐状态。
- 客户需求：需求跟进和推荐阿姨。
- 预约面试：预约记录管理。
- 接单申请：阿姨申请记录管理。
- 订单跟进：订单状态管理。
- 人工派单：派单记录管理。
- 门店信息：门店、店长、团队、坐标和图片。
- 服务中心：客户端首页服务说明和服务入口。
- 首页轮播：客户端首页公司展示图片。

## 权限边界

- 运营端可以管理日常业务模块。
- 管理端可以访问账号、管理看板和审计日志。
- 权限由后端判断，前端菜单只是体验层。
