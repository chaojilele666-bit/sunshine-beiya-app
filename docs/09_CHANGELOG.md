# 变更记录

## V2

- 后台主要资源迁移到 PostgreSQL。
- 保留 `Backstage/data.json` 作为历史备份和只读兜底。
- 增加 Docker PostgreSQL 本地流程。
- 增加后台 CRUD、人工派单、门店、服务模块、轮播、经营看板和操作日志。
- 增加门店详情和门店图片同步。
- 增加本地 HTTP 图片在微信开发者工具中的兼容转换。

## V3

- 从 V2 准备 V3 分支。
- 审计客户需求匹配闭环。
- 增加客户端首页公司展示轮播。
- 删除旧客户端绿色主卡片。
- 增加客户端快捷入口。
- 改造客户端服务中心。
- 调整后台 hash 路由模块页面。

## V3.1

- 增加客户需求匹配流程。
- 新增 `demand_matches`。
- 新增需求 accessToken hash。
- 新增小程序需求详情页。
- 新增推荐列表和确认/拒绝操作。
- 后台客户需求模块增加推荐阿姨操作。
- accessToken 从 URL query 改为 `X-Demand-Access-Token` 请求头。

## 服务中心

- 合并旧“公司服务”和“热门服务”为“服务中心”。
- `service_modules` 增加 `module_type`、图标、主题、点击目标字段。
- 客户端首页根据 `highlight` 和 `service` 分别展示说明和服务入口。
- 后台 `iconImage` 优先；没有图标时使用本地默认 SVG 图标。

- 生产服务器部署。
