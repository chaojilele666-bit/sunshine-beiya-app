# 北京阳光北亚家政后台一期

这个文件夹是后台雏形，先用于确认正式版后台要管理哪些内容，并覆盖小程序完整业务流程。

## 现在能做什么

- 管理账号入口和权限：客户端、阿姨端、运营端、老板端
- 老板端经营看板：客户点击、阿姨点击、客户信息量、阿姨信息量、发布量和状态统计
- 管理阿姨资料
- 管理客户需求
- 管理预约面试
- 管理阿姨接单申请
- 管理订单跟进
- 管理门店信息
- 管理客户端“公司服务”模块
- 管理首页轮播/推荐图
- 下拉选择服务类型、状态、是否显示，减少手填出错
- 阿姨管理支持上传阿姨照片、身份证、健康证、技能证书
- 公司服务模块支持上传展示图片，当前 demo 先保存为本地数据
- 提供小程序读取接口 `/api/miniprogram`
- 数据先保存在 `backend/data.json`

## 怎么运行

在项目根目录执行：

```powershell
node backend/server.js
```

然后浏览器打开：

```text
http://localhost:5177
```

如果系统里的 `node` 不能运行，可以用 Codex 自带 Node 路径：

```powershell
& "C:\Users\24225\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" backend/server.js
```

## 后面要接正式后端时怎么换

现在这个后台是本地 JSON 版，适合先定字段和流程。

正式上线建议换成：

- 微信云开发数据库
- 云函数接口
- 管理员登录
- 图片上传到云存储
- 小程序从云数据库读取阿姨、客户需求、门店和公司服务模块

## 小程序接口预览

后台首页右上角有“小程序接口预览”，对应地址：

```text
http://localhost:5177/api/miniprogram
```

这个接口会返回：

- 已认证阿姨
- 未成交/未取消的客户需求
- 显示中的门店
- 显示中的公司服务模块
- 显示中的首页轮播图

正式上线时，小程序首页、服务页和门店页就可以从这个接口对应的数据结构迁移到云数据库读取。
